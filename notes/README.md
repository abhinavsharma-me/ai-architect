# My Daily Notes

This directory contains my personal learning log. I use one Markdown file per day:

```text
day-001.md
day-002.md
...
day-110.md
```

The filename is the only convention:

```text
day-001.md
day-002.md
...
```

I write these notes for myself, but try to make them understandable to another person. I include explanations, examples, questions, mistakes, and useful links. The note template is only a starting point, not a required format.
