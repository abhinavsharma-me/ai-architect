# Knowledge Map

This is the map of topics I am exploring. It is not a syllabus or a promise to study everything in a fixed order.

## Foundations

- software architecture and modular design
- distributed systems, concurrency, consistency, and transactions
- databases, data modeling, queues, and event-driven systems

## AI systems

- transformer and inference mechanics
- tokens, context windows, KV caches, and structured outputs
- workflows, agents, memory, tools, MCP, and human approval
- multi-provider model routing and graceful degradation

## Production engineering

- timeouts, retries, idempotency, circuit breakers, and backpressure
- durable execution, Sagas, replay, and failure recovery
- observability, SLOs, incident response, and chaos testing
- cloud infrastructure, deployment, disaster recovery, and cost control

## Security and governance

- identity, authorization, ABAC, RLS, encryption, and secrets
- prompt injection, SSRF, tool security, and supply-chain security
- privacy, auditability, data lifecycle, and responsible AI
- SOC 2, ISO 27001, NIST, GDPR, India's DPDP Act, HIPAA, and the EU AI Act

## Knowledge systems

- document ingestion and structural chunking
- hybrid search, vector indexes, reranking, and GraphRAG
- permission-aware retrieval and citation verification
- evaluation datasets, agent testing, and release gates

The order will change as I learn. New notes may add topics, correct older notes, or remove ideas that no longer make sense.
